# OSS Rader 🚀

OSS Rader is a full‑stack platform designed to help developers discover, track, and explore open‑source projects with clarity and speed.  
This repository contains both the **frontend** and **backend** codebases, organized in a clean monorepo structure.

---

## 📂 Project Structure
oss-rader/ 
  frontend/   → React/Vite UI (coming soon) 
  backend/    → Express + TypeScript API 
  .gitignore 
  README.md


---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express
- TypeScript
- Nodemon + ts-node (dev)
- MongoDB + Mongoose (future integration)

### Frontend
- Next.js 16 (App Router)
- React 19
- TailwindCSS (planned)
- Server Components + API Routes (future integration)

## 🌿 Branching Strategy

I follow a simple, scalable workflow:

- `main` → stable, production-ready code  
- `dev` → active development  
- `feature/*` → individual tasks or modules
